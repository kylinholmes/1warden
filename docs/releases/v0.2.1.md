# 1Warden v0.2.1

本版包含 v0.1.0 之后已合入 main 的全部功能与修复。v0.2.0 因 Windows 打包检查失败未发布；本版修复了缓存旧安装包干扰当前版本打包的问题，保留原标签，不改写发布历史。

## 整理与合并

- 重复和疑似重复组新增「合并…」：选择主条目及来源，预览差异，逐项选择冲突内容后再确认。
- 主条目保存并核验成功后，来源移入可恢复的回收站；保存未确认时不处理来源。不调用永久删除。
- 合并保留网址、备注、自定义字段和密码历史；未选密码进入历史，未选名称、用户名及验证码密钥进入隐藏自定义字段。
- 密码及验证码密钥默认隐藏，按需单独显示；同名来源使用稳定编号和更新时间区分。
- 首版支持个人普通登录条目。带附件、通行密钥、共享权限、关联字段或无法完整读取内容的条目会明确阻止合并。
- 合并不是跨条目事务。来源变化会保留，网络导致处理结果不确定时提示同步核查；请勿盲目重复合并。

## 界面与编辑

- 全部生产 React 页面的原生下拉统一为共享控件，覆盖整理分类、主条目、文件夹、导入格式、信用卡品牌、网址匹配与自定义字段。
- 统一深浅主题、键盘导航、焦点恢复和弹窗内定位，修复入场动画期间下拉菜单误关闭。
- 收录 main 上已合并的详情字段点击复制、姓名标签、条目编辑及导航改进。

## 平台与验证

- 提供 Windows x64 安装包/免安装 EXE、Apple Silicon macOS 应用/DMG，以及 Chromium/Edge、Firefox 扩展。
- CI 包含类型检查、单元/集成测试、跨端界面和下拉控件、真实 Edge/Firefox 扩展、真实 Vaultwarden 协议以及 Windows WebView2 回归。只有全部发布检查通过后才发布资产。
- Windows 打包精确选取当前版本安装包；旧缓存不影响发布，当前版本缺失时拒绝拿旧包替代，并有实际 PowerShell 回归测试。

## 安装说明

Windows 包未做 Authenticode 签名；macOS 使用 ad-hoc 签名，未做 Developer ID 签名或公证；浏览器扩展仍需手动安装。macOS 支持签名更新并要求明确重启，Windows 使用新版安装包更新。请在替换程序前退出旧实例。

下载对应平台的文件，并按 `SHA256SUMS.txt` 核对。免安装 EXE 仍需 WebView2 Runtime，且与安装版使用同一应用数据目录。
