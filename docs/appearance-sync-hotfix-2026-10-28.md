# 0.2.11 外观点击与后台同步闪动修复

用户报告 Windows 免安装版打开外观页后持续刷新，切换主题与明暗模式时点击经常没有反应。

## 复现和原因

使用发布的 0.2.11 EXE、独立 APPDATA/LOCALAPPDATA/WebView 配置、合成加密账户测试。没有后台通知时，未观察到持续 DOM 重建。加入真实 SignalR MessagePack 通知，每 1200ms 推送一次、每次同步延迟 800ms 后，外观控件被禁用，模式点击被忽略，配色下拉无法打开。

- 每次后台同步都会暂时撤销当前同步验证状态。外观页把它当作整个账户尚未初始化，禁用整组控件；因此正常的后台同步也会吞掉点击。
- 条目详情使用 `条目 ID + 全局 revision` 作为 React key。全局 revision 在同步开始、结束及无关资料更新时变化，导致详情卸载、再次读取、重新播放淡入。
- 搜索结果也绑定全局 revision；刷新期间结果临时变成空数组，所选详情因此卸载，即使条目内容没有变化。
- 自动保存会在每次应用快照到达时重新计时。后台同步留下的可写窗口短于 650ms 时，待保存修改可能一直被推迟。

这里确认的是后台同步下的可复现机制；没有读取用户账户或追踪用户服务器的实际通知频率。

## 修复行为

已完成验证的同一解锁账户可在后台同步期间继续预览、暂存外观修改，实际加密写入仍等待同步完成。首次同步、锁定、账户切换和同步/资料错误仍限制编辑，不放宽保险库的验证或写入保护。

保存期限由用户编辑决定；背景快照不会延后它。同步结束时，已经到期的保存立即继续。

详情 key 改为条目自身的摘要内容，含 ID、updatedAt、收藏、文件夹等，无关快照保持原节点；真正更新条目时仍重新读取并恢复密码遮罩。收藏的局部更新不会返回新的 updatedAt，因此也必须比较实际摘要，不能只依赖时间戳。后台刷新保留相同查询的结果 ID，并用当前保险库摘要解析，删除的记录立即消失；不同查询不复用旧结果。

## 回归验证

- 控制器测试覆盖同步中暂存、完成后保存、首次未验证/锁定/换账户/错误拒绝编辑、无关快照不推迟保存。
- 真实 Provider 集成测试覆盖外观按钮可用性与页面节点保留。
- 详情交互测试分别覆盖空查询与活动查询，验证 DOM、焦点、已显示密码在无关同步中稳定，真实记录更新后重新遮罩。
- `scripts/appearance-sync-smoke.ts` 使用实际 Windows WebView2、200 条合成加密记录及真实通知连接；检查连续切换、最终保存、空闲同步无主题写入、无详情卸载、无偏好写回循环、真实条目更新仍生效。已加入原生 CI 套件。
- 发布的 0.2.11 在原生控件可用性断言失败；修复版通过相同复现。
