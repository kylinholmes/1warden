# 设置与条目编辑打磨

本次继续已确认的登录与快捷解锁布局，修复同步期间的设置操作，并统一主题、选择控件和编辑器细节。

## 行为

- 快捷窗口的顶栏使用“打开主窗口”图标。解锁和搜索状态均可操作，取消未完成认证并清空输入后收起快捷窗，恢复并聚焦主窗口。
- Ctrl+F 从保险库和设置进入条目搜索；编辑器等有草稿的浮层保留原内容与焦点。Windows WebView2 关闭浏览器自己的快捷命令，避免出现浏览器查找条；文字选择、复制和粘贴仍由系统处理。Ctrl+L 在浮层或传输期间也能锁定保险库。
- 外观和个人资料可在后台同步时编辑。外观立即预览，远端加密保存等待验证完成。首次快照只合并用户改动的字段；远端没有偏好时保留本账户的迁移或缓存外观，新账户不会继承上一账户的主题。已知远端冲突和保存失败仍保留草稿及恢复操作。
- 安全时限仅存当前设备。自动锁定支持 1、5、15、30、60 分钟；从原解锁时间计算，修改期限不重新计时，缩短到已过期时立即锁定，涵盖其他已解锁账户。剪贴板支持 10、30、60、120 秒，影响之后的复制。Windows 保留原有 owner 与私有标记校验，避免清除用户后来复制的内容。扩展仍使用其后台固定时限，界面显示只读值。
- 新建条目的八种类型图标复用侧栏语义色，窄屏类型下拉也保留彩色图标。
- 密码旁“生成”展开内联参数：长度 8–64、大小写、数字、符号、排除易混字符。展开、折叠和调整参数均不改密码；点击骰子图标才生成并填入，填入后遮罩。展开时在编辑器内滚动，完整露出参数并在页脚上方留出 12px，焦点保留在触发按钮；调整参数和折叠不会再次滚动。至少保留一种字符类别，保存期间不可操作；Escape 先收起参数区。此功能不用于账户主密码。

主题及分段按钮的逐项结论见 [主题与控件审查](theme-and-controls-review-2026-11-13.md)。既有入口布局见 [登录与快捷解锁](login-and-quick-unlock.md)。
