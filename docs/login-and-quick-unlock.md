# 登录与桌面快捷解锁

用户选定登录方案 A、快捷解锁方案 B。快捷解锁只用于桌面窗口；早期原型里的窄屏折叠方案不作为实现要求。本次延续现有主题、系统字体和 BrandMark，没有建立新的全局视觉规范。

## 已接受的布局

- 主窗口登录和解锁共用 AuthPage：品牌放在左上角，单列表单最大宽度 388px，水平居中。页头上下内边距 24px、左右为 `clamp(24px, 3vw, 36px)`；正文在所有宽度都从页头下方 24px 起排，不再按 600px 断点改变垂直位置。标题 28px，输入框至少 50px，主按钮至少 48px。登录的服务器身份始终可见，选择与测速收在“更改”中；自定义服务器地址保持可见、可编辑。
- 主窗口账户整行都是下拉触发器，最小高度 64px，显示头像、名称及邮箱。菜单使用共享 Select，额外显示完整服务器主机和路径及选中标记；既有账户原地切换，“添加账户”进入登录表单，并提供“返回账户”。账户解锁的连接摘要为一行主机与延迟，展开才显示完整 URL 和测速操作；没有默认的“下载未测试”行。
- 桌面快捷解锁：原生窗口为逻辑 800×440，125% DPI 下对应物理 1000×550。通用和 Windows Tauri 配置保持一致。多账户使用固定 240px 纵向账户栏，单账户省略侧栏；两种情况下右侧表单最大宽度均为 320px，整组垂直居中，内容过高时可滚动。输入框和主按钮高 36px，认证顶栏高 46px；账户行最小高度 64px、内边距 5px 10px、间距 10px，头像 40px。名称 13px、邮箱与服务器 12px，行高 1.35、行间距 2px；选中头像使用独立的纸面背景，保留清楚的字母轮廓。三条普通账户完整可见，更长列表纵向滚动。账户栏展示名称、邮箱、服务器主机及完整路径，长值换行；右侧不重复账户身份。密码步骤没有返回箭头；两步验证提供返回密码的按钮。没有手机断点。
- 文案只保留操作、身份、状态和必要的安全说明。解锁期间隐藏搜索框；不添加通用副标题或解释布局意图的文字。

## 行为边界

桌面和移动端主入口直接打开登录表单；有保存账户时优先进入上次选中账户的解锁页。偏好单独存放在 `1warden.lastAccount`，只有公开的 serverUrl 和 email；启动时按规范化身份匹配有效保存账户。偏好缺失、损坏或对应账户已移除时，退回首个有效账户。选择已有账户会更新偏好，但不改变保存列表顺序；新账户登录成功才更新偏好，登录失败和“添加账户”的空账户导航都不覆盖它。

根登录和解锁页面不显示返回首页。账户下拉直接切换已有身份，选择“添加账户”才打开新登录表单；“返回账户”恢复此前的解锁页，切换时清空未提交密码。注册返回按钮标为“返回登录”，退出登录也回到登录表单。该入口行为由 main.tsx 的 directEntry 启用，扩展继续使用原有入口流程。

登录继续使用既有认证、注册、证书确认、两步验证和公开字段草稿流程；服务器变化时清空已输入的主密码。密码显示按钮复用共享 PasswordInput。主密码使用原生 label/for 关联，显示按钮位于标签之外，输入框的可访问名称保持为“主密码”。中文占位提示使用普通 UI 字体，输入的秘密字符仍使用等宽字体。

快捷解锁优先选中当前搜索账户，没有匹配项时选第一个账户，并聚焦密码框。账户列表支持上下方向键及 Home/End；Enter 提交，Esc 关闭窗口。切换账户、两步验证返回、关闭或转去登录会取消当前认证；过期结果不得解锁另一账户或重新打开已关闭的流程。提交、切换、关闭和窗口失焦时清空主密码。

快捷窗口右上角在固定按钮前提供“打开主窗口”图标，解锁和搜索状态均可使用；32px 按钮配 17px 图标，悬停提示和可访问名称均为“打开主窗口”。点击取消当前快捷认证并清空未提交密码，然后收起快捷窗口、显示并聚焦主窗口；最小化的主窗口会恢复。

Connect、Unlock 和快捷认证协调器共用 [authenticationErrorMessage](../apps/desktop/src/screens/auth-error.ts)：未知认证或解密错误显示中性的重试提示；网络、密码、超时、频率限制等已知错误保留针对性的说明，账户选择恢复提示也保留。两步验证错误指向验证码，内部 MAC 等诊断不进入表单文案。

布局入口为 [AuthPage](../apps/desktop/src/components/AuthPage.tsx)、[AuthAccountSwitcher](../apps/desktop/src/components/AuthAccountSwitcher.tsx)、[QuickUnlockPanel](../apps/desktop/src/components/QuickUnlockPanel.tsx) 和 [桌面样式](../apps/desktop/src/styles.css)。这些尺寸和布局只约束本次入口与解锁表面，不扩展为全局 token。
