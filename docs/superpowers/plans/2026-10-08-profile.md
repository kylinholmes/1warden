# Profile Implementation Plan

**Goal:** Encrypted, synchronized Profile with avatar/name editing, local presentation cache, colorful shared UI and working account switching.
**Architecture:** Vault codec -> application service/cache -> existing trusted RPC -> shared UI.
**Spec:** ../specs/2026-10-08-profile-design.md

## Constraints and review focus
- No password or full-note persistence; cache whitelist only.
- Preserve unknown JSON/record metadata; reject unknown versions, stale saves and corrupt data.
- Account isolation, logout/write races, failed writes and sync deletion require regression coverage.
- Image budget includes Base64 and encryption expansion, not merely uploaded file size.
- Preserve existing panel motion and palette work; no writes to real personal data. Repository commits/push are now explicitly requested by the user.

## Tasks
- [x] Codec: add packages/vault/src/profile.ts + tests for marker, validation, metadata preservation, size and revisions.
- [x] Cache/service: add application/profile-cache.ts + tests; wire snapshot/saveProfile through desktop and extension RPC. Verify create/update encryption, filtering, lock/logout, stale async results.
- [x] UI: add ProfileEditor, avatar compression and display component; wire Settings/Sidebar/Unlock and preview fixtures. Browser-check saving and re-opening with synthetic state.
- [x] Account menu and switching: remembered identities and cached avatars, same/different backend selection, retained unlocked sessions (later user revision), Add Account Back navigation, selected-only lock/logout cleanup and keyboard/error handling.
- [x] Integration: typecheck, full tests, desktop/mobile/extension builds and headless UI/extension checks; inspect palette screenshots and update handoff.

Execution: root implements Profile; separate palette worker edits non-overlapping shared theme/components. Final independent code review after integration.

## Follow-up: account navigation and retained sessions

The menu keeps only **登出**. Adding an account can return to the original session, including failed login and popup close/reopen, without retaining a master password.
