# 交互逻辑审查与修复记录

日期：2026-10-16。

本轮围绕用户能否连续完成任务审查：入口是否明确、成功后是否继续原任务、失败能否重试、返回与取消是否有效、切换账户是否串状态、输入与反馈是否一致。审查覆盖欢迎/登录/注册/服务器选择、锁定解锁、账户切换、快捷搜索与复制、条目编辑、密码生成器、浏览器凭据保存提示。以下记录已确认并修复的问题；不将未复现的风险记为缺陷。

## 快捷窗口的完整流程

多账户时先选择头像，只有一个账户时直接进入密码输入。选中已解锁账户直接搜索；锁定账户在当前快捷窗口输入主密码，需要二次验证时继续在当前窗口完成。成功后回到搜索并保留原查询，显示当前账户，允许再次切换。

- 选账户保留大头像和一行邮箱，支持横向滚动、键盘选择与悬停反馈。认证时显示邮箱和服务器，避免同邮箱的不同服务器混淆。
- 密码或验证码错误显示在当前表单，恢复输入焦点；等待期间阻止重复提交。
- 返回和 Escape 按验证 → 密码 → 账户选择逐层返回；单账户的密码页可直接关闭。即使焦点在顶部固定按钮，Escape 仍遵循当前步骤。
- 关闭、失焦取消和账户切换会清理临时输入，忽略旧请求结果。取消旧请求不会误锁另一个账户，已被原生层接受的成功结果也不会因页面切换而再次锁回去。
- 超时提示保留在表单中，允许重新输入，不会被稍后到达的取消回执抹掉。
- 认证通过即进入搜索，后台同步进度单独显示；同步失败提供重试。搜索结果先于认证回执到达时不会提前卸载表单并取消刚完成的解锁。

主窗口继续持有保险库会话。快捷窗口的临时密码经原生、限定调用窗口的一次性信箱传递，事件只传请求标识；操作绑定账户和本次窗口/请求生命周期。保留项目已有的服务器认证和二次验证要求，没有新增离线解锁策略。

## 其他已修复的交互问题

| 场景与触发方式 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 账户提供多种二次验证方式 | 固定使用第一种，甚至对不支持的方式展示验证码框 | 可选已实现的验证方式；不支持的方式明确标识，不再提供无法完成的表单 |
| 二次验证的“记住设备” | 界面承诺记住，但没有完成令牌保存链路 | 移除无效选项，避免用户误以为后续无需验证 |
| 主窗口密码错误后重试 | 焦点未可靠返回输入框，可能重复提交 | 等待结束后恢复焦点并阻止重复提交 |
| 验证码错误 | 被解释为主密码错误，引导用户修改错误的字段 | 显示验证码相关错误，网络和限流反馈保持区别 |
| 服务器更新密钥派生参数后解锁 | 旧缓存使正确密码持续失败 | 仅在使用缓存且认证被拒绝时刷新参数；参数确实改变才重试一次 |
| 登录成功、首次同步较慢时切换/锁定/添加账户 | 登录一直等待全部同步；后续状态可能覆盖用户的新操作，原账户可能未及时记住 | 认证成功即接入会话、记住规范化账户信息并继续同步；后续切换/锁定/退出仍生效 |
| 注册请求或本地密钥生成期间点击返回 | 返回被禁用，或迟到结果把用户带回注册流程 | 返回停止等待并使旧操作失效；已提交的注册可能仍完成，界面提示可稍后登录确认 |
| 新增条目时切换类型再切回来 | 已填写的类型专属字段丢失 | 本次编辑保留各类型草稿；只保存最终选中类型的内容，关闭后清理草稿 |
| 浏览器凭据保存提示已过期，点击重试 | 持续打开同一个失效提示 | 失效链接提示一次并清理，重试读取当前待处理项；网络失败保留链接供重试 |
| 复制密码后重新生成，或剪贴板写入尚未完成时重新生成 | 新密码仍显示“已复制”，可能让用户误认为剪贴板已更新 | 新值清除旧复制反馈；旧异步结果不能恢复错误提示，写入期间仍阻止重复复制 |

## 范围与验证边界

没有使用用户真实密码完成自动化登录，也没有向用户真实保险库写入测试数据。快捷窗口的真实服务认证由协调器/原生测试覆盖，真实浏览器演练使用模拟认证。

macOS、Linux、移动端原生运行和 Firefox 实机交互未在本机执行；移动端前端与 Firefox 扩展已构建验证。本轮未新增邮件验证码发送、Duo、FIDO2 保险库登录或记住设备令牌持久化，未实现的验证方式明确反馈。

参考 [1Password Quick Access](https://support.1password.com/quick-access/) 的当前任务连续性与账户范围选择，以及 [Bitwarden 登录与解锁说明](https://bitwarden.com/help/understand-log-in-vs-unlock/) 的状态区分。快捷窗口内输入密码是本项目根据用户要求作出的设计，不声称复刻这些产品未公开说明的具体界面。
