# 整理与分析：确认合并

分析本身仍只读取本机已载入的保险库，不上传给 AI，也不会自动修改记录。重复和疑似重复组提供「合并…」入口；疑似重复不代表内容相同，需要逐项核对。

## 操作流程

1. 选择主条目，并勾选本组中要合入的来源。主条目的记录 ID 和加密密钥保留。
2. 载入预览：重新读取服务器记录，展示内容汇总、冲突和限制；此时不写入。
3. 对每个冲突明确选择采用哪个来源。来源带稳定编号和更新时间；密码、验证码密钥默认隐藏，只在单独点击「显示」时读取。返回或关闭会清除显示值。
4. 确认后先保存主条目，再解密服务器返回的记录并核验合并内容。只有通过核验后，才逐条将其他来源移到回收站，不调用永久删除。
5. 查看结果。部分来源未处理或结果不确定时，先同步检查，不要再次盲目合并。回收站记录可恢复。

网址及其匹配方式、自定义字段、不同备注和密码历史合并保留；任一来源已收藏，则保留收藏。未选用的密码放入历史密码；未选用的名称、用户名和验证码密钥保存在隐藏自定义字段中。文件夹及自动填充设置有冲突时也需选择。内容汇总包含主条目原有内容，不是新增数量。

## 当前范围与安全边界

- 支持同一重复组内 2–50 条个人普通登录记录。
- 包含附件、通行密钥、关联字段、未识别服务器字段、读取失败字段、共享/组织权限或主密码再次验证的记录暂不允许合并；预览会说明原因，不静默跳过这些内容。
- 预览凭证仅在所有者服务内存中有效，10 分钟过期且只允许一次提交；切换账户、锁定或记录变化后需要重新预览。
- 提交前核对每条记录的远端指纹，主条目保存使用乐观版本检查；移入回收站前再检查来源是否变化。
- Vaultwarden 不提供跨条目事务，也不提供带版本条件的移入回收站接口。读取来源后到移入回收站之间的竞争窗口无法完全消除；网络超时也可能导致结果暂时未知。因此不会承诺原子合并，结果会提示同步核查。
- 这不是备份工具；重要保险库仍应保留独立的加密备份。

## 统一选择控件与回归

「整理分类」「合并主条目」、文件夹、导入格式、信用卡品牌、网址匹配和自定义字段选择统一使用共享 `Select`，不依赖 Windows/浏览器原生下拉菜单。控件支持深浅主题、键盘选择、焦点恢复和弹窗内定位；暂不可编辑的设置显示为只读值。

回归入口：

```powershell
bun run check
bun run test:ui -- ui --only=select
bun run test:ui -- extensions --only=edge-extension
```

单元及集成测试覆盖冲突保留、读取/保存/核验失败、并发更新、锁定、一次性凭证和迟到响应。真实扩展测试使用临时 Edge 配置与合成 loopback 保险库，验证选择主条目、查看冲突、确认写入和来源移入回收站，不操作真实保险库或系统剪贴板。
