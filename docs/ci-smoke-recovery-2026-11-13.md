# 2026-11-13 CI 冒烟测试修复

首次失败运行：[43385491196](https://github.com/kylinholmes/1warden/actions/runs/43385491196)，源码提交 `432a5a7`。类型检查、单元测试、UI 冒烟、macOS 与 Windows 编译、扩展打包均通过；失败发生在原生账户详情和扩展冒烟测试中。

## 原因与修复

- 原生账户详情仍等待旧首页的登录按钮。改为验证原生直接登录入口，并沿“添加账户 → 返回账户”验证已解锁会话、头像及账户信息；扩展继续验证其账户首页，第二个隔离客户端的同步检查保留。
- 服务器测速测试点击了紧凑登录表单中折叠的控件。共享辅助方法先等待新表单挂载，再展开“更改”；下拉断言等待真实可见的选项。测速失败、重试、结果跨注册与登录页面共享的断言均保留。
- Firefox 159 不再接受旧命令行标记作为扩展页自动化授权。按 [Mozilla Remote Agent 文档](https://firefox-source-docs.mozilla.org/remote/Security.html#system-access) 添加 `MOZ_REMOTE_ALLOW_SYSTEM_ACCESS=1`，仅传给已显式请求该权限的隔离 Firefox 子进程，不修改宿主进程环境或生产扩展权限。保留旧标记以兼容较早版本。
